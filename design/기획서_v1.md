## 2. 한 줄 콘셉트

**「사씨남정기: 지워진 이름」**(가제) — 번진 먹 때문에 필사본에서 **이름과 호칭이 지워졌다.** 필사가가 되어 장면을 살피고, 지워진 자리에 알맞은 인물을 채워 넣어 누명의 연쇄를 복원한다. 다 채우고 나면 학생 손으로 완성한 **인물 관계도와 사건첩**이 남는다.

- 학생들이 어려워하는 세 가지를 게임의 재료로 바꾼다.
  - 인물이 많다 → **관계도**가 장마다 한 칸씩 자라며, 한 번에 새 인물 3~5명만 등장한다.
  - 호칭이 여러 개다 → **호칭 잇기**가 곧 복원 작업이다. '한림', '교 낭자', '투부', '낭군'이 누구를 가리키는지 장면 속에서 판단한다.
  - 갈등이 복잡하다 → **빈칸 복원**으로 "누가, 누구와 짜고, 무엇으로, 누구에게 누명을 씌웠나"를 문장으로 재구성한다.
- 원작 구조와 게임 구조가 겹친다. 원작은 **위조된 증거에 속은 가장(유연수)**의 이야기다. 플레이어는 같은 증거를 보면서 **속지 않는 사람**이 된다(설계 이론 03 §2.1 루도내러티브 조화).
- 세책방 틀은 조선 후기에 실제로 있었던 소설 대여 문화를 빌린 것이다. 그러나 필사가와 복원 작업은 지어낸 설정(虛)이다.

### 장마다 새 기믹 하나(기승전결)
- 서장·1장 **호칭 잇기** → 2장 **빈칸 복원** → 3장 빈칸 + 서스펜스 → 4장 **여정 잇기·꿈과 현실** → 5장 **복원 확인(정답 공개)** → 종장 **죄목 따지기**(앞의 기믹을 모두 합친 마무리)

### 3장의 서스펜스 연출
장주 사건은 학생이 막을 수 없다. 교씨 쪽 계략을 **먼저 보여 준 뒤**, 한림이 판단하는 장면을 한 줄씩 지켜보게 한다(히치콕의 탁자 밑 폭탄). 학생의 할 일은 사건을 바꾸는 것이 아니라 **"어디서 누가 알아챌 수 있었나"를 표시하는 것**이다. 결과 화면의 디브리핑 질문과 연결한다.

## 5. 메커닉 상세

### 5-1. 호칭 잇기 (서장·1장, 이후 계속)
- 필사본 쪽에 **번진 호칭**이 강조되어 있다. 호칭을 누르고 → 아래 인물 초상을 누르면 연필 표시가 된다(추측).
- 연필 표시 3개가 모이면 **[맞추어 보기]**. 셋 다 맞아야 먹 도장으로 확정된다(Obra Dinn식 묶음 확정). 틀리면 "몇 개 맞음"만 알려 준다.
- 확정된 호칭은 **호칭 도감**의 그 인물 칸에 들어가고, 이후 본문에서는 작은 초상 표시가 자동으로 붙는다(도입 모드). 복습 모드에서는 자동 표시가 없다.
- 함정 호칭을 일부러 넣는다: '소사'(유연수가 아니라 아버지), '투부'(한림이 사씨를 가리켜 씀), '낭군'(교씨가 동청을 부를 때), '교 부인'(폐출 뒤 정실이 된 교씨).

### 5-2. 빈칸 복원 (2장~)
- 사건 하나 = 장면 삽화 1장 + 조사 지점 2~4곳 + 빈칸 문장 1~3줄.
- 단어 카드: 인물(호칭 변이형 포함), 물건(옥지환·저주 글·목인·편지), 행동(훔치다·넘기다·보이다·위조하다).
  - 호칭 변이형은 모두 정답으로 받는다(예: '유 한림'과 '한림'). 호칭 학습이 여기서도 이어진다.
- **전체 제출만 판정**한다. 결과는 "모두 맞음 / 2칸 이하 틀림 / 3칸 이상 틀림" 세 단계(Golden Idol식 부분 피드백).
- 힌트 사다리: 2번 틀리면 틀린 칸에 빗금, 3번 틀리면 근거가 된 조사 지점이 빛남, 4번째는 정답과 풀이. 힌트를 써도 감점하지 않고 **'도움 사용'으로만 기록**한다.
- 조작은 **탭-탭**(카드 누르고 빈칸 누르기)이 기본이다. 끌어다 놓기도 되지만 선택 사항이다(태블릿 오작동 대비).

### 5-3. 여정 잇기·꿈과 현실 (4장)
- 명나라 남방 지도(순천부 → 장사·동정호·소상강 → 황릉묘 → 군산 수월암)에 사건 카드를 순서대로 놓는다(관동별곡의 여정 퍼즐과 같은 계열).
- **꿈과 현실 가르기**: 황릉묘 장면의 인물·행동 카드를 '꿈속'과 '깨어난 뒤' 두 칸에 나눈다. 아황·여영은 꿈속에서 위로·예언하고, 여승은 현실에서 배를 저어 온다. 2016 학평과 2018 수능이 모두 물은 지점이다.

### 5-4. 복원 확인 (5장)
- 설매가 한림에게 진상을 털어놓는 장면은 원작 사건이다(#41). 이 장면에서 앞서 학생이 복원한 사건첩 쪽마다 **"설매의 고백으로 확인됨"** 도장이 찍힌다. 추리가 원작의 진상 공개와 겹치는 순간이다.

### 5-5. 죄목 따지기 (종장, 클라이맥스)
- 원작 결말에서 예부상서 유연수가 교씨를 데려와 **죄를 하나하나 따진 뒤 처형한다**(#50). 법정은 지어내지 않는다.
- 죄목 카드(예: "사씨를 모함하려고 저주 글을 꾸민 일")마다 학생이 **사건첩에서 복원한 쪽**을 증거로 제시한다. 맞으면 붓글씨로 죄목이 적힌다.
- 죄목 목록은 원작 사건만 쓰고, 문장은 새로 쓴다. 이본마다 개수가 다르므로(경판 계열은 열 가지) 개수는 묻지 않는다.

### 5-6. 상시 메타 UI
- **관계도**: 사건이 확정될 때마다 인물 카드와 선이 추가된다. 선에는 반드시 관계 라벨을 붙인다(혼인, 첩, 부자·모자, 고모와 조카, 주종, 사통, 모함, 도움). 원작에서 확인된 선은 실선만 쓴다(추측 선 없음).
- **호칭 도감**: 인물마다 '이름 / 신분·관직 호칭 / 관계 호칭 / 남이 낮춰 부르는 말' 칸.
- **사건첩**: 복원한 사건 문장 모음. 종장의 증거함이 된다.
- **이본 노트**: 이본이 갈리는 세부를 모아 둔다(§7).

| 原文 | 한지 두루마리, 붉은 낙관 `原文`, 명조 | 한문본 회목 12개와 부찰 제목, 김춘택 서문 등 **퍼블릭 도메인 원문만**. 음과 풀이를 붙인다 |
| 이야기 풀이 | 필사본 쪽(한지 바탕, 명조) | 원작 줄거리를 **현대어로 새로 쓴 글**. 번역서·수능 지문 문장은 쓰지 않는다. 첫 화면에서 "원문이 아니라 풀어 쓴 글"임을 밝힌다 |
| 해석 | 쪽빛 테두리, `해석` 태그 | 숙종·인현왕후 풍자설, 가부장제 비판 등 "~로 해석되기도 한다" |
| 게임 설정(虛) | 청록 테두리, 고딕, `게임 설정` 태그 | 세책방, 필사가, 번진 먹과 복원 작업, 여백의 낙서 힌트. 처음 나올 때 "원작에서는 →" 카드를 붙인다 |

- **AI가 그린 그림에는 글자를 넣지 않는다.** 지명·인물명은 코드로만 표시한다.
- 폭력 장면(장주의 죽음, 교씨 처형)은 직접 그리지 않고 상징과 서술로만 처리한다.

### 이본 처리 원칙
- **판정하는 사실**: 모든 이본에 공통인 것만. 예) "교씨·동청 일당이 장주를 죽이고 사씨의 시비 춘방을 끌어들여 사씨가 시킨 일로 꾸몄다."
- **보여 주되 판정하지 않는 세부**: 한문본 계열을 따르고 이본 노트에 표시. 예) 장주를 직접 해친 사람(한문본: 동청의 지시를 받은 납매 / 경판본: 설매), 여승 이름(묘희/묘혜), 무녀 이름(이십낭/십랑), 유 소사의 이름.
- 이름이 갈리는 인물은 이름 대신 호칭으로 부른다(유 소사, 여승, 임씨).

## 9. 화면·기기

- 휴대폰 세로: 위 40% 장면 삽화, 가운데 필사본 쪽(문장·빈칸), 아래 25% 엄지 영역(단어 카드·인물 초상). 핵심 결정은 탭 한두 번.
- 태블릿·PC 가로: 왼쪽 장면+필사본, 오른쪽 관계도·도감(2단).
- 터치 대상 44px 이상, 글자 크기 조절, 소리 없이도 완주 가능. 게임 오버·시간 제한 없음.

## 10. 기술

- **HTML + CSS + 순수 JavaScript(빌드 도구 없음)**. 글과 카드가 중심이라 캔버스 대신 DOM으로 만든다(글자 선명, 반응형, 접근성).
- 내용은 모두 `js/data/`의 데이터 파일(`story.js` 사건·문장·빈칸, `people.js` 인물·호칭, `notes.js` 이본 노트·허구 카드)로 분리한다. 교사가 코드를 몰라도 고칠 수 있게 한다.
- 진행은 브라우저(localStorage)에만 장 단위로 저장한다.
- 글꼴: 필사본용 명조와 UI용 고딕을 게임에 쓰인 글자만 남긴 부분 글꼴(woff2, SIL OFL)로 함께 넣는다.
- 소리: WebAudio 합성(국악 음계의 짧은 효과음·배경음).
- 배포: GitHub Pages(배포 직전에 확인).

## 12. 결과 화면

- 학생이 완성한 **관계도**(가장 강한 진행감), 호칭 도감 채움률, 사건첩, 오답 노트(오답 유형: 호칭 혼동·순서 혼동·인과 혼동·인물 역할 혼동).
- **디브리핑 질문**(해석 층위): "유연수는 어느 시점에 무엇을 확인했어야 했나?", "사씨가 다시 첩을 권하는 결말을 어떻게 볼까?"
- 완주증: 이름 입력(기기 안에서만), 캡처 방법 안내, '이미지로 저장' 버튼.

## 14. 구현하면서 바뀐 점 (2026-09-28)

- **사실 검증 반영**(`design/원작_검증노트.md`): 빈칸 정답을 모든 이본에 공통인 사실로 다시 맞췄다.
  - 저주 사건: "동청이 글씨를 썼다"는 한문본에만 있어 빈칸에서 빼고 이본 노트로 옮겼다. 한림의 처리도 "불태워" 대신 "덮어 두었다"(2008 수능 지문과 공통)로 바꿨다.
  - 장주 사건: 동청이 나오지 않는 이본이 있어 "교씨 쪽 사람들"로 바꾸고, 빈칸은 두 부인·교씨·장주·춘방·사씨로 정했다.
  - 노래 사건의 장소, 옥가락지 매듭의 색, 냉진이 옥가락지를 보인 방식, 여승이 황릉묘 안으로 찾아온 점, '낭군' 대사의 위치 등을 원작 표현에 맞췄다.
  - 설매의 고백에 "상공께서 귀양 가신 것도 교 부인이 동청과 꾸민 일"(모든 이본 공통)을 더했다.
  - 5장에 10회 회목을 더하되 글자 수 문제를 풀이에 밝혔다.
- **관계도**: 세로로 긴 도면. 선이 10개를 넘으면 인물을 눌러야 그 인물의 관계 이름이 보이고, 한 번 더 누르면 자세히 볼 수 있다. 관계도 채우기에서는 빈자리와 이어진 선의 이름을 늘 보여 준다.
- **게임 설정 카드**를 하나 더했다: 장면 그림은 AI 상상화라 세부가 원작과 다를 수 있음.
- **배경음은 기본으로 끔**(교실 소음). 효과음은 켬.
